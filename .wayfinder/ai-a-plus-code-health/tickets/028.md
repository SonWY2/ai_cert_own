## Question

사용자가 정한 `gpt-6-sol` 대 `gpt-6-luna`를 어떤 경로로 호출하고, 구독형 프록시의 토큰 사용량으로 실제 API 비용까지 검증할 수 있는가?

## Resolution comment

강한 단일 모델 후보를 `gpt-6-sol`, 작은 모델 전체 시스템 후보를 `gpt-6-luna`로 정한다. 최종 버전·가격·프롬프트는 파일럿 뒤 final holdout 전에 동결한다. OMP 모델 목록은 별도 `openai-oauth@2.0.0` 프록시의 **계정별 접근 가능성**을 입증하지 않는다. `--models`로 목록을 강제하지 않고 인증된 `/v1/models`와 실제 호출을 확인해야 한다. 프록시는 공식 유료 OpenAI API가 아니라 ChatGPT Codex OAuth를 이용하는 제3자 서버이다. 설치는 저장소 밖 임시 디렉터리에 스크립트 실행 없이 수행했다. v24 작성 당시 인증 파일이 없어 기동에 실패했으나, 이후 소유자의 로그인 및 v25의 모델별 비소스 호출 성공은 [029](029.md)에 기록한다. 인증 파일·토큰을 이동하거나 프로젝트에 저장하지 않는다.

v24에서는 선언된 RunManifest와 정확히 일치하는 루프백 주소만 기존 Anthropic HTTPS 외 모델 전송 주소로 허용했다. 당시 선택한 `/v1/chat/completions`는 로그인 뒤 두 모델 모두 500 응답을 반환해 v25에서 **`http://127.0.0.1:10531/v1/responses`로 교체**했다([029](029.md)). OAuth 서버는 루프백에서만 돌리고 서버의 요청 기록은 켜지 않는다. 각 Git SHA·모델별로 소유자가 내용을 보고 단일 사용 영수증을 별도로 발행해야 전송한다. 기존 `diagnose_approved.py`의 다섯 관점 호출만으로 강한 모델 **1회** 대 작은 모델 **전체 F 시스템**의 비교가 성립하지 않는다. 개발용 루프백 모의 서버 검사와 비소스 연결 확인은 결함 진단이나 금액 영수증이 아니다.

OAuth 구독형 서버가 반환하는 토큰은 실측 가능한 사용량이지 호출별 **실제 청구액**이 아니다. 과거 v23의 `billed_micro_usd` 계약을 0으로 채워 결과를 위조하거나 모델별 가상의 가격을 청구 비용으로 표시하지 않는다. 실제 비용 우월성을 최종 주장하려면 제공자 원본 청구 근거·독립 판정·안전한 실행 환경·사전 동결 holdout을 별도로 갖춰야 한다. 현재 전송 승인을 비롯한 남은 실행 조건은 [029](029.md)에 남긴다.
