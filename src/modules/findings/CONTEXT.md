# Module Context: findings

`admit`은 source 단계 기록을 인용한 외부 제공 가설을 위치·원인·조건·영향·단일 검증 행동 기준으로 검증하고 같은 정체성을 병합한다. source hash가 있다는 사실은 결함의 증명이 아니다. 충돌하는 근거 경로·발생 조건·taxonomy·검증 행동을 한 위험으로 임의 병합하지 않는다. 모든 출력은 `deferred`, `basis: source_only`다.

정체성은 저장소·원인 심볼·실패 원리·발생 조건·영향 다섯 값으로만 결정한다. 줄 번호·관점·근거 나열 순서는 포함하지 않는다. 이전 위험 ID는 정확한 정체성 일치에만 재사용한다. 범위가 일부인 점검에서는 누락 위험을 `resolved`로 판정하지 않는다.

`priority_rows`는 한 위험 ID에 영향·조건, 변화·근거, 다음 행동 하나와 독립적인 사용자 행동을 묶는다. `record_action.py`는 사용자의 대화형 확인을 받은 뒤 `actions.append_action`으로 source 점검별 추가 전용 기록을 저장한다. `read_actions`는 마지막 선택만 복원한다. 심각도와 예상 시간은 외부 가설 입력이며 독립 확인 수치가 아니다. 사용자 선택은 근거 판정이 아니다. 모델 호출·실행 oracle·최종 보고서는 구현되지 않았다.
