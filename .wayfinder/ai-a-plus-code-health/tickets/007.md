## Question

2024년 이후 공개 논문·공식 자료에서 graph-aware retrieval, execution-guided reasoning, verifier·critic, learned tool routing, uncertainty calibration, test-time compute, temporal change-risk 중 코드 결함·성능 진단에 재현 가능한 개선 근거가 있는 기법은 무엇이며, 패치 생성 성과를 진단 성과로 전이할 수 없는 지점과 비용·실패 조건은 무엇인가?

## Resolution comment

- 연구 자산: [AI 코드 진단 최신 기법 근거 조사](../research/ai-methods-evidence.md)
- 결론: 가장 직접적인 근거는 lexical 검색과 typed graph를 결합한 위치화, 실패 재현·coverage를 이용한 execution-guided 진단, baseline/scaled workload의 differential profiling이다.
- learned router, critic, conformal calibration, 다중 표본 추론은 코드 진단 직접 근거가 부족하거나 비용·자기확증 위험이 있어 격리 실험 후보로만 둔다.
- 패치 통과율은 진단 정확도·원인 설명·위험 우선순위의 증거로 대체할 수 없다.
