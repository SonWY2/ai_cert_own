## Question

Python 3.14·FastAPI·asyncio 중심 코드 건강검진의 공개 실제 사례, 정상 대조군, 합성 결함 기반을 구성하기 위해 어떤 공개 저장소·dataset을 고정 후보로 삼을 수 있으며, 각 후보의 immutable revision·license·Python 3.14 실행 가능성·API/비동기/다중 파일/성능·동시성 strata·재현 workload·사전학습 오염 위험은 무엇인가?

## Resolution comment

- 연구 자산: [Python 3.14 + FastAPI·asyncio 코드 건강검진용 공개 포트폴리오 근거](../research/fastapi-portfolio-evidence.md)
- 파일럿 후보는 Langflow v1.11.5, Prefect 3.8.4, FastAPI Users v15.0.5, `full-stack-fastapi-template` 고정 commit이다.
- FastAPI·Starlette 자체는 framework 계측 보정에만 사용하고 제품 건강 점수에 합산하지 않는다. vLLM은 GPU가 확보된 조건부 성능 lane으로 제한한다.
- 공개 저장소는 사전학습 오염 가능성이 높으므로 최종 승자 판정은 익명 실제 사례와 별도 합성 holdout이 담당한다.
- Python 3.14 metadata는 실행 보장이 아니며 실제 dependency·workload 재생은 구현 단계에서 별도 검증한다.
